# dsh-git-assistant

`v0.2.1` · DeepSeek Harness Git 工作台

一个用在 [DeepSeek Harness](https://github.com/deepseek-ai) 里的 Git 工作台：把仓库、工作树、分支、改动、diff、提交图形和 GitHub 议题，收进左侧栏、会话顶部标签页和右侧栏，让你尽量不离开对话就能完成日常 Git 操作。

> **状态：v0.2.1（开发中预览）。** npm 包与安装方式暂未发布，当前仅用于试用与功能展示；接口和交互仍会继续调整。

## 功能

### 三个入口

- 左侧栏 **Git** 图标：整页主面板；
- 会话顶部标签 **Git**：在当前对话内打开；
- 会话右侧栏 **Git** tab：和原生对话并排使用。

### 仓库与工作树

- 标题栏下拉选择仓库、分支与工作树；
- 每个工作树是一张可独立操作的卡片，显示分支、ahead/behind、是否有冲突；
- 工作树排序：主工作树优先，其次有改动的工作树，再按最近提交时间排序；
- 切换分支、新建分支、同步（pull）和推送。

### 更改与提交

- 「已暂存的更改 / 更改」分组，支持单独暂存、取消暂存、放弃，以及整组操作；
- 文件行悬停显示操作图标，状态字母（M/A/D/R…）靠右对齐；
- 多选（⌘ / Ctrl / Shift）后批量暂存、取消暂存或放弃；
- 提交按钮拆分：提交、提交（修改上次）、提交并推送、提交并同步；
- 提交信息输入与流程状态提示，操作完成后自动刷新。

### Diff 查看

- 统一 / 并排两种视图，并排模式自动换行，避免左右互相覆盖；
- 分页渲染：大 diff 先渲染首屏，滚动继续加载，避免一次性卡死；
- 超大 hunk 默认折叠成一行，可手动展开；
- hunk 之间被 Git 省略的「N 行未变更，点击展开」，按需读取真实上下文；
- 文件头部显示 Material 文件图标与增删行数；
- 顶部工具栏可选择**已提交但未推送**的提交，查看这次提交的全部文件改动，并支持全部折叠 / 展开。

### 提交图形

- 底部可折叠的提交图形抽屉，可拖拽调整高度；
- GitHub 风格的车道配色与平滑曲线，支持分支范围 / 全部引用切换；
- 悬停查看提交详情，展开查看该提交的文件树与单文件 diff；
- 无限滚动，按需加载更多提交。

### 文件浏览

- 每个工作树的**完整文件系统**树（不局限于 Git 跟踪文件），默认折叠、懒加载目录；
- Material Icon Theme 图标映射；
- 图片、PDF、音频、视频预览，二进制文件给出提示；
- 文件右键菜单，可复制路径、在系统中打开等。

### 议题（GitHub Issues）

- Git 工作台里新增「议题」tab：**卡片网格**代替传统列表；
- 每张卡片显示编号、状态、标题、标签、评论数、更新时间，以及父 / 子议题徽标；
- 支持搜索、按打开 / 关闭 / 全部筛选；
- 点击卡片在**左侧宽栏**查看详情：Markdown 正文、标签、作者、评论数、父 / 子议题跳转、在 GitHub 打开；
- 评论按需加载并渲染 Markdown；
- 点击已选中的卡片可取消选中；
- 数据通过本机已登录的 `gh` 读取，只读（暂不支持评论、关闭等写操作）。

### 与对话协作

- 把文件从文件树拖进对话输入框，生成附件；
- 选中 diff / 文件内容中的文本，可直接引用到对话输入框；
- 中英文界面自动跟随 Harness 语言设置，明暗主题跟随应用主题。

## 性能与数据策略

- 所有 Git 命令走 Host 侧 argv 调用（不经过 shell），路径经过校验，写入前经过确认；
- diff 在 Host 侧解析为文件与 hunk，客户端只接收结构化数据；
- diff 结果按「HEAD / 暂存区 / 文件状态」缓存，写操作后精确失效；
- Host 通过 SSE 推送 `.git/index`、`HEAD`、refs 等变化，客户端即时刷新；状态轮询作为兜底，失败指数退避、页面隐藏暂停；
- 暂存 / 取消暂存采用乐观更新，失败自动回滚；
- 更改 / 文件两个面板保持挂载，切换视图不丢状态，隐藏时停止请求；
- GitHub 议题采用**滑动缓存 + 增量同步**：
  - 首次全量拉取后记录同步时间；
  - 之后用 `since` 只拉取变化的 issue，未变化的继续留在缓存；
  - 议题 tab 活跃时每 2 分钟做一次带 `ETag` 的条件轮询，**304 不消耗 GitHub 额度**；
  - 本地 `git push`、DSH 里的 `gh` 命令、`.git/refs` 变化都会触发增量同步；
  - 只有变化的 issue 才失效其详情与评论缓存。

## 技术结构

- `src/index.js`：Host 端插件，提供 `/git-assistant/api/*` 与 GitHub Issue / `gh` 集成；
- `src/client.js`：浏览器端单文件 UI（工作台、diff、图形、文件树、议题看板）；
- `cordis.patch.yml`、`package.json`：插件清单与客户端注入声明；
- `scripts/`：smoke 渲染、车道算法校验、jsdom 交互回归；
- `locale/`、`icon.svg`：文案与图标。
